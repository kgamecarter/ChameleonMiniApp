# Chameleon Mini App

A Android GUI for the ChameleonMini device.

* **[Chameleon Mini App on Google Play](https://play.google.com/store/apps/details?id=tw.kgame.chameleonminiapp)**

## Features

*   **USB OTG Connection**: Seamlessly connect to your ChameleonMini RevE device.
*   **Slot Management**: Configure and control all 8 slots.
*   **Card Emulation**: View and modify UID, Memory Size, and Mode for each slot.
*   **Button Configuration**: Customize Button and Long Press Button actions.
*   **Data Transfer**: Upload and Download card dump files.
*   **Tools**: Includes `mfkey32` attack support.
*   **Device Info**: View firmware version and other device details.
*   **Localization**: Supports English and Traditional Chinese.

## Requirements

*   ChameleonMini RevE
*   Android 4.4 or later
*   USB OTG cable

## Installation

### Google Play
Download the app directly from the [Google Play Store](https://play.google.com/store/apps/details?id=tw.kgame.chameleonminiapp).

### Build from Source
1.  Ensure you have the [Flutter SDK](https://flutter.dev/docs/get-started/install) installed.
2.  Clone this repository.
3.  Run `flutter pub get` to install dependencies.
4.  Connect your Android device.
5.  Run `flutter run` to build and install the app.

## Usage

1.  Connect your ChameleonMini RevE to your Android phone using a USB OTG cable.
2.  Open the Chameleon Mini App.
3.  Grant USB permissions if prompted.
4.  The app should automatically detect and connect to the device.
5.  Swipe between tabs to manage different slots.
6.  Use the menu to access Settings, Device Info, or perform actions like Upload/Download.
